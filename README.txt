Firmo – خريطة الزراعة (PWA)
==============================

الملفات (ارفعها كلها معاً في نفس المجلد):
  index.html · manifest.webmanifest · sw.js · icons/

الخطوة 1 — الاستضافة (مرة واحدة، مجاناً، HTTPS مطلوب للتثبيت)
  أسهلها: افتح app.netlify.com/drop واسحب المجلد كاملاً → تحصل على رابط فوراً.
  أو: GitHub Pages / Cloudflare Pages / أي استضافة HTTPS.
  للتجربة المحلية: داخل المجلد شغّل  python -m http.server 8000
  ثم افتح http://localhost:8000  (localhost يقبل التثبيت أيضاً).

الخطوة 2 — التثبيت على سطح المكتب
  Windows / Linux / ChromeOS : Chrome أو Edge أو Brave → زر ⬇️ داخل التطبيق
                               أو أيقونة التثبيت في شريط العنوان.
  macOS                      : Chrome/Edge كما سبق، أو Safari 17+ ← ملف ← إضافة إلى Dock.
  Android                    : Chrome ← ⋮ ← تثبيت التطبيق.
  iPhone / iPad              : Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية.
  (Firefox على سطح المكتب لا يدعم التثبيت.)

العمل بدون إنترنت
  أول زيارة (بإنترنت) تحفظ التطبيق في الجهاز، وبعدها يعمل بالكامل بدون اتصال.
  بياناتك تُحفظ محلياً على الجهاز (localStorage) — استخدم «تصدير» للنسخ الاحتياطي.
  البيانات خاصة بكل جهاز/متصفح ولا تنتقل تلقائياً بين الأجهزة.

التحديث
  عند تعديل أي ملف غيّر VERSION داخل sw.js (مثلاً v3) ثم أعد الرفع.
