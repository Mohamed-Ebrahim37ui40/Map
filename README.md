# Firmo – تطبيق ويب يعمل أوفلاين

هذا التطبيق عبارة عن PWA (Progressive Web App) ويعمل على Windows وmacOS وLinux وAndroid وiOS.

## التشغيل محليًا
1. فك ضغط الملف.
2. افتح `index.html` في المتصفح، أو شغّل خادمًا محليًا:
   - Python: `python -m http.server 8080`
   - ثم افتح: `http://localhost:8080`

## التثبيت كتطبيق
- **Android / Chrome:** افتح التطبيق ثم اختر “تثبيت التطبيق” من قائمة المتصفح.
- **iPhone / iPad / Safari:** شارك الصفحة ثم اختر “إضافة إلى الشاشة الرئيسية”.
- **Windows / macOS / Linux:** من Chrome أو Edge اختر أيقونة التثبيت في شريط العنوان، أو القائمة ثم “تثبيت Firmo”.

## العمل بدون إنترنت
يخزّن Service Worker ملفات التطبيق في ذاكرة المتصفح بعد أول فتح، لذا يعمل التطبيق لاحقًا بدون اتصال.
